# RoboControl 融资文档

## 1. 项目概述

### 1.1 市场机遇

全球机器人市场正在爆发式增长：

- **2025年全球机器人市场规模**：$210B（来源：IFR World Robotics 2023）
- **中国机器人市场**：连续9年全球最大工业机器人市场
- **服务机器人增速**：年复合增长率（CAGR）25%+
- **关键驱动力**：劳动力成本上升、人口老龄化、AI技术成熟

### 1.2 行业痛点

| 痛点 | 现状 | RoboControl方案 |
|------|------|-----------------|
| 延迟高 | WebRTC方案200-500ms | 自研协议<50ms |
| 并发低 | 万级连接 | 千万级连接 |
| 不可靠 | 断线率5-10% | P2P+Relay<0.1% |
| 成本高 | 按WebRTC分钟计费 | SaaS订阅，成本低80% |
| 扩展难 | 需要专业团队 | 开箱即用 |

### 1.3 解决方案

RoboControl是一个**自研协议栈**的实时机器人远程控制平台：

- **不是WebRTC包装** — 从底层UDP协议开始设计
- **千万级并发** — 单机10M连接，水平扩展
- **P2P穿透+智能Relay** — 99.9%连接成功率
- **端到端加密** — AES-256-GCM / ChaCha20-Poly1305
- **多路摄像头** — 每台机器人支持8路视频流

## 2. 技术壁垒

### 2.1 自研协议栈

```
┌─────────────────────────────────────────────┐
│              应用层 (API/SDK)                │
├─────────────────────────────────────────────┤
│   多流复用层 (控制流 + 4路视频流)            │
├─────────────────────────────────────────────┤
│   安全层 (DTLS-like + ECDHE + AES-GCM)      │
├─────────────────────────────────────────────┤
│   可靠性层 (SACK重传 + RTO)                 │
├─────────────────────────────────────────────┤
│   拥塞控制层 (CUBIC)                        │
├─────────────────────────────────────────────┤
│   传输层 (UDP + P2P穿透 + Relay)            │
└─────────────────────────────────────────────┘
```

### 2.2 核心技术优势

| 维度 | WebRTC | RoboControl |
|------|--------|-------------|
| 协议 | DTLS/SRTP over UDP | 自研DTLS-like over UDP |
| 握手 | ICE/STUN/TURN | ECDHE + STUN-like |
| 拥塞控制 | GCC (Google CC) | CUBIC (RFC 8312) |
| 丢包恢复 | NACK + FEC | SACK + 快速重传 |
| 连接数 | ~1万/服务器 | 1000万/服务器 |
| 延迟 | 200-500ms | <50ms |
| 视频流数 | 1路 | 8路 |
| 复杂度 | 极高（数百万行代码） | 低（~5000行C代码） |

### 2.3 知识产权

- 自研协议设计（非基于RFC标准的WebRTC）
- CUBIC拥塞控制在UDP上的应用
- P2P穿透+Relay智能切换算法
- 预计申请3-5项发明专利
